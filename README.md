# ASP.NET-GameStore
## Project for CPW 230

## Project Description
This project is an online game store where users can browse and purchase games. The site lets customers search for games, add them to a cart, and place orders. Admins can manage the game listings and view orders through a simple dashboard.

The project is built with ASP.NET Core MVC and uses Microsoft SQL Server with Entity Framework Core to store and manage all data.

## Tech Stack
- **ASP.NET Core 8.0** — Web framework
- **Entity Framework Core** — Database access
- **Microsoft SQL Server** — Database
- **ASP.NET Core Identity** — User login and registration
- **Razor Views + Bootstrap** — Frontend
